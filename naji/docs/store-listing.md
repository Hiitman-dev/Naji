## ۸) بسته‌بندی MSIX — چک‌لیست فنی

راحت‌ترین مسیرها (به‌ترتیب توصیه):

**الف) MSIX Packaging Tool (روی خود ویندوز):**
1. `NajiSetup.exe` را نصب کنید.
2. MSIX Packaging Tool را باز کنید → «Create package from installed apps».
3. ناجی را انتخاب کنید؛ فرم امضای بسته را روی «Sign with a certificate»
   بگذارید و همان `certs\code_signing.pfx` را بدهید.
4. فایل `.msix` حاصل را در Partner Center آپلود کنید.

**ب) PyInstaller + msix CLI (تکرارپذیر برای ریلیزهای بعدی):**
```powershell
pip install msix
# بعد از build_exe.bat:
python -m msix pack "dist" -p "Naji.appxmanifest" -c "certs\code_signing.pfx" -pw %NAJI_CERT_PASS%
```
(یک `Naji.appxmanifest` حداقلی با Identity نام پکیج Partner Center بسازید.)

- Identity در Partner Center را یک‌بار بسازید و در manifest ثابت نگه دارید —
  هر ریلیز فقط Version را بالا ببرید (هم‌گام با `main_window.VERSION`).
- چون exe فعلاً onefile است، نصب‌شدن از استور بدون تغییر کارکرد انجام می‌شود.
- بعد از تأیید استور، لینک استور را در `landing/index.html` هم اضافه کنید.
