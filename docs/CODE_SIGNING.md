# راهنمای امضای دیجیتال (Code Signing) — ناجی v6.0

> **چرا این مهم‌ترین کار بعد از این نسخه است؟**
> الان وقتی کاربر `Naji.exe` را دانلود می‌کند، ویندوز Defender/SmartScreen
> هشدار «ناشناس / Windows protected your PC» می‌دهد و خیلی‌ها همان‌جا
> منصرف می‌شوند یا آنتی‌ویروس فایل را پاک می‌کند. یک گواهی Authenticode
> معتبر این هشدار را برمی‌دارد و اعتماد (و نرخ نصب) را به‌شدت بالا می‌برد.
> این سند مسیر ارزان تا حرفه‌ای را قدم‌به‌قدم توضیح می‌دهد.

---

## وضعیت فعلی پروژه (بعد از v6.0)

زیرساخت امضا **کامل آماده** است و فقط گواهی کم است:

| فایل | چه کاری انجام می‌دهد |
|------|----------------------|
| `build_exe.bat` | بعد از build، اگر `certs\code_signing.pfx` وجود داشته باشد، `dist\Naji.exe` را با signtool امضا و timestamp می‌کند |
| `setup.iss` | نصاب `NajiSetup.exe` **و** uninstaller را با همان گواهی امضا می‌کند (`SignTool=` + `SignedUninstaller=yes`) |
| `docs/CODE_SIGNING.md` | همین راهنما |

---

## گام ۱ — خرید گواهی (سه گزینه، از ارزان به حرفه‌ای)

### گزینه‌ی A — Certum (ارزان‌ترین، ~۲۵–۴۰€ در سال) ✅ پیشنهاد برای شروع
1. به `shop.certum.eu` بروید → **Open Source Code Signing** (برای پروژه‌های
   متن‌باز ارزان‌تر است و ناجی روی گیت‌هاب منتشر می‌شود).
2. احراز هویت (اسکن مدارک + ویدئو) معمولاً ۱–۳ روز طول می‌کشد.
3. گواهی را در قالب **PFX/P12** دانلود کنید.

### گزینه‌ی B — Azure Trusted Signing (~۹٫۹۹$/ماه) ⚡ ساده‌ترین امضا
- گواهی را خودِ مایکروسافت می‌دهد و SmartScreen اعتمادش خیلی سریع ساخته می‌شود.
- نیاز به حساب Azure دارد؛ امضا با ابزار `trusted signing` انجام می‌شود
  (به‌جای signtool؛ در `build_exe.bat` فقط مسیر ابزار را عوض کنید).
- محدودیت جغرافیایی: برای مشترکین خارج از آمریکا/اروپا ممکن است در دسترس
  نباشد — قبل از خرید چک کنید.

### گزینه‌ی C — SSL.com / Sectigo / DigiCert OV (~۷۰–۲۰۰$/سال)
- گران‌تر ولی شناخته‌شده‌تر؛ برای برندینگ حرفه‌ای مناسب است.
- نسخه‌ی EV (~۲۵۰$/سال) بلافاصله اعتماد SmartScreen می‌گیرد؛ OV معمولاً
  بعد از چند هفته build امضاشده، reputation می‌سازد.

> **نکته‌ی مهم:** از اکتبر ۲۰۲۳ گواهی‌های جدید باید روی **توکن سخت‌افزاری**
> (USB Token یا HSM ابری مثل Azure Key Vault / SSL.com eSigner) باشند.
> Certum هنگام خرید، گزینه‌ی «SimplySign» (توکن ابری) می‌دهد — راحت‌ترین
> راه این است که PFX را از SimplySign به یک فایل `.pfx` اکسپورت کنید.

## گام ۲ — آماده‌سازی فایل گواهی

فایل نهایی باید `certs\code_signing.pfx` (کنار پوشه‌ی پروژه) باشد:

```bat
mkdir certs
rem فایل pfx/p12 دانلودشده را به certs\code_signing.pfx کپی یا rename کنید
```

⚠️ **هرگز `certs\` را کامیت نکنید.** (همین حالا به `.gitignore` اضافه کنید:
`certs/`)

---

## گام ۳ — امضا

```bat
rem رمز گواهی را در متغیر محیطی بگذارید (نه داخل فایل‌ها!)
set NAJI_CERT_PASS=YourPfxPassword

build_exe.bat      :: گام ۵/۶ خودکار exe را امضا می‌کند
build_setup.bat    :: Inno خودش installer + uninstaller را امضا می‌کند
                    (یک‌بار: Inno Setup > Tools > Configure Sign Tools >
                    Name: signtool  |  Path: مسیر signtool.exe)
```

signtool جزو **Windows SDK Signing Tools** است؛ اگر نبود، از
https://developer.microsoft.com → Windows SDK فقط گزینه‌ی
«Signing Tools for Desktop Apps» را نصب کنید.

---

## گام ۴ — تأیید امضا

```bat
signtool verify /pa /v dist\Naji.exe
signtool verify /pa /v Output\NajiSetup.exe
```

باید `Issued to: Naji` و `Timestamp: OK` ببینید.

## چک‌لیست بعد از امضا

- [ ] اولین ریلیز امضاشده را در GitHub Releases بگذارید.
- [ ] چند روز/هفته صبر کنید تا reputation SmartScreen ساخته شود
      (برای OV معمولاً لازم است چند صد دانلودِ امضاشده دیده شود).
- [ ] در Microsoft Store هم منتشر کنید (نوشته‌ی آماده: `docs/store-listing.md`)
      — نصب از استور هیچ هشداری ندارد.
- [ ] اگر گواهی را عوض کردید، هر دو فایل `build_exe.bat` و `setup.iss`
      چیزی برای تغییر ندارند — همان مسیر `certs\code_signing.pfx` کافی است.

## سوالات پرتکرار

**آیا با گواهی OV باز هم هشدار SmartScreen می‌آید؟**
چند هفته اول بله؛ با جمع‌شدن reputation (دانلود و نصب‌های سالم) هشدار
حذف می‌شود. EV این دوره را نمی‌گذراند ولی گران است.

**آیا آنتی‌ویروس‌های ثالث (Kaspersky و…) هم اعتماد می‌کنند؟**
درصد زیادی از هشدارهای «ناشناس» به‌خاطر نبود امضا است؛ بعد از امضا
+ چند هفته انتشار پایدار، نرخ هشدار به‌شدت کم می‌شود.

**Timestamp چرا مهم است؟**
`/tr http://timestamp.digicert.com` باعث می‌شود امضا بعد از انقضای گواهی
هم معتبر بماند — هر دو اسکریپت build این کار را خودکار انجام می‌دهند.
